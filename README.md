# Practica de Manejo masivo de datos [Titanic_Bigdata_KDAR]

> A lo largo de esta practica se trata de realizar un analisis a un data set del TITANIC, en donde se pone en juego conocimientos sobre procesamiento de datos, analisis de datos y sobre todo una comunicación por medio de repertorios de forma que el estudiante pueda aprender a poder realizar proyectos de manera profesional.

---

## DataSet 
- train.csv(61.19 kB)
- https://www.kaggle.com/c/titanic/data?select=train.csv
- Datos sobre supervivientes, porcentajes y estadisticas descriptivas.
---

## Objetivo
- ¿Qué porcentaje de pasajeros sobrevivió?
- ¿Cómo cambia la supervivencia entre hombres y mujeres?
- ¿Cómo cambia la supervivencia según la clase del pasajero?
- ¿Qué grupos de edad presentan mayor supervivencia?
- ¿Viajar solo o acompañado parece estar relacionado con la supervivencia?
- ¿Existe alguna relación entre la tarifa pagada y la supervivencia?
---

## Requisitos 
- Se requiere Python y de ser posible una distribución de Linux
- Dependencias descargadas del archivo Requirements.txt en un entorno
---

## Instalación

Sigue estos pasos para ejecutar el proyecto en tu entorno local:

### 1. Clonar el repositorio
git clone https://github.com/XxRaliugaRdzxX/Titanic_Bigdata_KDAR.git

### 2. Entrar al directorio del proyecto
cd Titanic_Bigdata_KDAR

### 3. Instalar las dependencias
- Primero el entorno con el comando `python -m venv .venv`
- Despues activar el entorno `source .venv/bin/activate`
- Al final descargar las dependecias con `pip install -r requirements.txt`


### 4. Iniciar el proyecto
- Correr el comando del script del análisis con `python src/analysis.py`

## 5. Conclusiones 

- Despue del analisis, se llego a la conclusión que la supervivencia en el siniestro no fue un evento de probabilidad aleatoria. El análisis de los datos demuestra de forma estadística que el proceso de evacuación siguió estrictamente un protocolo social y naval. La regla de mujeres y niños primero, explica las altas tasas de supervivencia en la variable de género y edad, mientras que la variable de Clase y Tarifa revela que la posición socioeconómica y la ubicación física en el barco jugaron un rol determinante en la capacidad de alcanzar los botes salvavidas a tiempo.
